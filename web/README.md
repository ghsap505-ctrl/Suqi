# Souqi Web (سوقي — نسخة الويب)

نسخة الويب المتجاوبة من منصة **سوقي**، مصممة للعمل بسرعة عالية على الهواتف والحواسيب والشبكات الضعيفة، وتعمل مع نفس قاعدة بيانات Firebase Firestore أو في وضع العرض التجريبي (Demo Mode) بدون مفاتيح.

## المميزات الأساسية
- واجهة عربية (`RTL`) افتراضية مع زر التبديل للإنجليزية (`LTR`).
- صفحة هبوط تسويقية متكاملة (المزايا، خطوات العمل، الباقات، الأسئلة الشائعة).
- دليل متاجر (`/explore`) مع البحث والتصفية حسب المدينة.
- واجهة متجر عامة (`#/s/<slug>`) مع تصنيف المنتجات، البحث، السلة، وإرسال الطلب المنسّق إلى واتساب مع تنبيه واضح بعدم تأكيد الطلب إلا بعد رد التاجر.
- لوحة التاجر لإدارة بيانات المتجر، الأقسام، المنتجات، وحالات الطلبات.
- لوحة الإدارة لتوثيق المتاجر، تعديل الباقات، وتفعيل الاشتراكات يدوياً.

## التشغيل المحلي

```bash
npm install
cp .env.example .env.local
# أضف مفاتيح Firebase Web الخاصة بمشروعك في .env.local (أو اتركه فارغاً لوضع Demo Mode)
npm run dev
```

## البناء والاختبار

```bash
npm run build
# تشغيل اختبارات منطق السلة وواتساب (Node 22+)
npm test
```

## النشر المجاني (Cloudflare Pages / GitHub Pages / Vercel)
- **Build command**: `npm run build`
- **Build output directory**: `dist`
- نظراً لاستخدام `Hash Routing` (`#/s/slug`)، لا يتطلب إعداد إعادة توجيه خادم معقدة على GitHub Pages أو الاستضافات الساكنة.
